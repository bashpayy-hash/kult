## 1. Продукт и концепт
Бөлек («отдельный, особый»; до 12 ноября — Shaqyru) — пилот закрытого lifestyle-комьюнити в Алматы. Участницы (1–3k
подписчиков) получают ужин или услугу в заведении, публикуют сторис с
личной ссылкой `/{участница}/{заведение}`. Подписчики бронируют по ссылке
или называют фразу «я от {имя}». Цель пилота — гостей на один визит
участницы, порог 2. Бесплатно, без оплаты и логина участниц.

- Локальная база: Postgres 16 в контейнере сессии
  (`/usr/lib/postgresql/16/bin`, порт 54329), миграции
  `npm run db:migrate`, сброс демо-данных `npm run db:seed`.

## 3. Стек
Next.js 16.4 (App Router, Server Actions, `proxy.ts` вместо middleware),
React 19, Tailwind 4 (токены в `src/app/tokens.css`), postgres.js по
`DATABASE_URL` или `NETLIFY_DB_URL` (Netlify Database, миграции в
`netlify/database/migrations/` применяет деплой), файлы в Netlify Blobs
(`STORAGE_BACKEND=blobs`; Supabase Storage и локальная папка — запасные
варианты в `src/lib/storage.ts`), адаптер `@netlify/plugin-nextjs`
в `netlify.toml`, шрифт —
одна гарнитура `@fontsource-variable/inter-tight` в разных начертаниях +
`public/fonts/inter-tight-tenge-v1.woff2` (₸). Сеть сессии: окружение `kult` (iitaly.net и CDN Higgsfield
разрешены).

  создание пары, загрузка скрина сторис и фото заведения, CSV.

## 7. Что не проверено или требует внимания
- Число заведений Алматы в источниках расходится (3 522 за 2025 против
  2 427 по Qazstat за 2024); в питче — 2 427. Статус закона о кальянах на
  ноябрь 2026 не проверен, но реклама кальяна запрещена в любом случае.
- Сторис участниц, скорее всего, подпадают под маркировку рекламы (с
  2.03.2024): нужна метка «Жарнама / Реклама» — в питче это стоит как план
  продукта, в коде её ещё нет.
- Демо-данные живут в базе продакшена. Перед запуском — новая миграция,
  удаляющая их по id; `0005` не трогать (Netlify проверяет контрольные
  суммы применённых миграций).
- CDN Netlify кэширует фото заведений на год (ключи с UUID не
  повторяются): удалённое фото ещё доступно по старой ссылке, но нигде не
  показывается. Скрины сторис не кэшируются.
- Supabase и Vercel как хостинг не проверялись: путь описан в README как
  запасной.
- Казахские тексты — вычитать носителю.
- Файлы дизайна владельца (`DESIGN (47).md`, `tokens (45).json`,
  `variables (45).css`, `theme (44).css`) в сессию не попали — свести с
  `tokens.css`, когда появятся.
- Репозиторий по-прежнему называется `kult`; переименование на GitHub —
  только по просьбе владельца.
- Имена в русских фразах не склоняются («от Камила»): так задано брифом
  («я от {имя}»).
